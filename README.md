# The Last Wall

Incremental fortress-defence game built in Godot 4.x (GDScript). Windows first, Steam later.

## Branches

- `master`: golden source, receives releases only.
- `develop`: integration branch. Feature work merges here after approval.
- Feature branches: `feature-SVTLW-<n>` from `develop`, merged by pull request.

See [CONTRIBUTING.md](CONTRIBUTING.md) for commit and pull request rules.

## Layout

- `docs/` design, technical and balance documents
- `game/` Godot project
- `tests/` automated tests
- `assets/` art, audio and credits
- `tools/` balance simulator and build helpers
